# 方法と限界

## 書き起こし
1回目：Claude が画像を目視で読んだ（`data/tr1_before_corrections.txt`）。次に2回の直しをした。

1. 別の読み手との食い違いと通らない語を画像で見て直した（差分 42 行）。この直しは Claude の目視だけによる。
2. 通らない語・不確かな語を画像の行で見て、直す候補 38 か所を出し、**平文を見せない2択**で別のモデル（Claude Sonnet）に判定させた。問いは「この前後の数字の間の数字は A か B か」だけで、どちらが1回目の読みかも伏せた。

   | 区分 | 結果 |
   |---|---|
   | 候補 38 か所 | 新しい値を選んだ 10、元の値を選んだ 26、決められない 2 |
   | そろった記号の抜き取り 80 と仕込みの誤り 10 | 90 問すべて元の値を選んだ（有効性の確認。形の似た数字との2択） |
   | 点の印の問い | 候補 8 のうち YES 7、対照 6 のうち YES 0 |

   新しい値に直したのは、その 10 か所だけ。元の値が選ばれた 26 か所は直していない。その多くは、語としては誤りでも、ペンの字がそのとおりである（書き手の誤りとみる）。文脈から候補を出した私の見立ては 10/38 しか支持されなかったので、文脈による直しは信用しないほうがよい。全部 `data/image_check.tsv` にある。
   このほかに、点で消された 75（efforts の語）を `~75`、数字でない筆の跡とみた 1 か所を `~6` とし、48,45 を画像どおり 4845 に直した。

Sonnet の問いへの答えは、2回の走らせ方の失敗（画像の上限で表示されず、見ずに答えを書いた分があった）の後の、問題番号を画像に焼き込んだ回だけを使った。

## 2回目
Claude Sonnet：19ページ全部。3段に切った画像を1枚ずつ読ませた。10ページ（p15 p16 p17 p03 p05 p07 p09 p11 p19 p14）は上の直し1の後、9ページは直し2の後に読んだ。全体 93.3%（値。分母 3,914）、名前 93.1%。

OpenAI Codex（codex-cli 0.163.0-alpha.10.2、gpt-6-astra、推論 high、3段に切って幅 2048px、空のフォルダから実行、コマンドの実行なし）：17ページ。**利用上限に達して p14・p19 は読めていない。** 直す前の1回目と値 91.1%（分母 3,446）、直した後と 91.3%。

比べ方：語末の点が 0・1 に見えるので3桁は頭の2桁にそろえ、カンマの見落としに備えて4桁は2桁ずつに分けた（両方の読みに同じ処理）。そろえない一致はこれより低い。ページごとの値は `src/agreement.py` で出る（最低は Sonnet の p16 87.7%、Codex の p12 83.5%）。

独立性の限り：
- Sonnet は1回目と同じ Claude の系統である。
- Codex の 91.3% は、食い違いを見て直した後の値なので独立と呼べない。独立と呼べるのは 91.1%。
- 画像での確かめは Claude と Sonnet だけで、**Codex は利用上限で参加していない**。
- 見た範囲：通らない語 33 と不確かな語の行は全部見た（語 504 の行は Sonnet の2択だけで、私は見ていない）。そろった記号は抜き取りの 90 問だけで、残りは1回目と2回目の一致によるのみである。

## 語の割合の数え方
`data/reading.txt` が語ごとの読みである。読みの語が英語の語で、鍵で読んだ字がその語の綴りの部分列になれば通る（母音を省く書き方なので部分列で比べる）。? の語と符号は通るに数えない。

緩めた扱い（いずれも結果の数字を上げる方向である）：u=v、i=j。同じ字の連続は1字に数える。10・12 は読み飛ばしてよい。19 は a か e。56 は y か w（duty・piety と what・with）。これらは鍵の使われ方を見て決めた。一部は読みを作った後に足した。辞書は wordfreq、/usr/share/dict/words と短い追加（revd、buchanan、mussulmans、irremidiable、judgement、chimerical）で、語末の1字を除いた形も認める。

**語の単位と記号の単位の両方を載せる。** 目録の基準（「トークンの 95% が意味をなす」）は記号の単位である。ただし、この手紙では先に語の単位で測り 89.8% が出て、直しの後に 92.9% となり、その後で記号の単位を足した（96.7%）。記号の単位では、語が読めていて1〜2記号だけ合わない語の、その記号だけを通らないに数える（語の記号の3分の1を超えて合わないときは語全体を数える。2 と 3分の1 は、1語を1か所の誤りで救う範囲に絞るために置いた数）。

読みは文脈で語を当てて作ったものなので、部分列の判定は本来ゆるい。読みに依らない検証は対照だけである。

## 対照
字の値を1000回かき混ぜて、数字の語の骨組み（母音を除く）が英語上位4万語の骨組みと同じ語の数を比べた（`src/control.py`）。値が少ない例から決まっている記号（出現12回以下の32記号）だけのかき混ぜも行った。どちらも本物以上は0回。

## 較正
なし。当時の解読文も刊本も見つからない。同じ手紙の別の写し（Quadruplicate と書かれているので複数あるはず）が Grenville 文書にあるかは確かめていない。

## そのほかの限界
- 画像の解像度は幅 1102px で、より大きい画像は見つからない。
- 鍵の値は全部、文脈から決めた。独立した鍵はない。
- 語の符号 4087・5089・4600 の値は分からない。
